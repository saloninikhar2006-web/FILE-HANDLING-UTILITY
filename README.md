🔹 Objective:

To develop a Java program that performs basic file operations such as:

Writing data to a file
Reading data from a file
Modifying file content

🔹 Features:

*Write Operation

*Appends user input to the file.

*Read Operation

*Displays file contents line by line.Modify Operation

*Replaces a specific word with another word in the file.

*Menu-Driven Interface

*Easy user interaction via console.

🔹 Technologies Used:

*Java I/O (File, FileWriter, Scanner)The program uses a menu system.

*Users choose an operation (Write/Read/Modify).

*File is stored locally (sample.txt).

*Modify operation reads entire content, replaces text, and rewrites file.

*Exception Handling
